# MochiDrop Site

Local static site adapted from the reference site.

- `privacy.html`: iOS / iPadOS privacy policy
- `android_privacy_policy.html`: Android privacy policy
- `android_terms_of_use.html`: Android terms
- `index.html`, `marketing.html`, `android_marketing.html`: game pages
- `support/index.html`: support page

Game name, icon, and screenshots use the MochiDrop project resources. Dates are October 13, 2026. Policy text and contact email follow the supplied reference; SDK disclosures have not been independently audited against the new game. Old canonical URLs were removed because a new public domain was not provided. Screenshots are actual development-build captures.

Preview: `python3 -m http.server 8000` from this directory.
